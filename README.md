# Data-Science-Internship-Project
# SyntecxHub Data Science Internship Projects

This repository contains the projects completed as part of the **SyntecxHub Data Science Internship Program**. The projects focus on **data analysis, visualization, statistical insights, and business problem-solving using Python and data science libraries**.

## 📌 Internship Domain
**Data Science**

## 🛠️ Tools & Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Data Visualization
- Exploratory Data Analysis (EDA)

---

#  Assignments Overview

## Assignment 1 – Exploratory Data Analysis
Performed exploratory data analysis on structured datasets to identify trends, distributions, missing values, and key statistical insights.

### Key Tasks
- Data cleaning and preprocessing
- Statistical summaries
- Distribution analysis
- Correlation analysis
- Data visualization

---

## Assignment 2 – Statistical Plots & Distribution Analysis
Analyzed data distributions using statistical plots and identified trends, skewness, and outliers.

### Key Tasks
- Histograms
- KDE plots
- Boxplots
- Outlier detection
- Distribution comparison
- Statistical interpretation

---

## Assignment 3 – COVID-19 Data Analysis
Performed country-wise COVID-19 time series analysis to identify trends, peaks, and transmission patterns.

### Key Tasks
- Daily and weekly case computation
- Country-wise comparison
- 7-day rolling averages
- Peak detection
- Trend visualization
- Basic reproduction insight comparison

### Insights Generated
- Country transmission trend comparison
- Peak outbreak periods
- Spread pattern visualization

---

## Assignment 4 – Sales Data Analysis
Conducted sales data analysis to derive business insights and identify performance trends.

### Key Tasks
- KPI computation
- Revenue analysis
- Average order value analysis
- Regional performance analysis
- Product performance analysis
- Sales trend visualization
- Business recommendations

### KPIs Analyzed
- Total Revenue
- Average Order Value
- Top Performing Regions
- Product Performance
- Profit Margin Analysis
